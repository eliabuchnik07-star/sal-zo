# סל זול

אתר שמשווה את מחיר סל הקניות בין הסניפים בעיר שבחרת.

## איך זה עובד

- **מקור המחירים:** קבצי המחירים שרשתות השיווק מחויבות לפרסם לפי חוק קידום התחרות בענף המזון (שקיפות מחירים).
- **עדכון:** סוכן אוטומטי (GitHub Actions, הקובץ `.github/workflows/update.yml`) רץ כל שעה, מוריד את הקובץ העדכני של כל סניף, ומפרסם את האתר מחדש.
- **מלאי:** הערכה לפי "מועד המכירה האחרון" שמופיע בקבצים (`LastSaleDateTime`). זו לא ספירת מדף.
- **תמונות:** מ־Open Food Facts לפי ברקוד, נבדקות פעם ביום.

## רשתות מחוברות

- שופרסל ✓
- רמי לוי, טיב טעם, דור אלון, פרשמרקט, סטופ מרקט, קשת טעמים, פוליצר ✓
- קינג סטור, מעיין 2000, זול ובגדול, שפע ברכת השם, סופר ספיר, שוק העיר ✓
- ויקטורי, קרפור/יינות ביתן, אושר עד, יוחננוף, מגה, סיטי מרקט: האתרים שלהם לא עונים לשרתים מחוץ לישראל
- חצי חינם: חוסם גישה אוטומטית

## הרצה ידנית

```
python3 scripts/fetch_prices.py   # מוריד מחירים ל-site/data
python3 scripts/fetch_images.py   # מחפש תמונות
cd site && python3 -m http.server  # האתר בכתובת http://localhost:8000
```
